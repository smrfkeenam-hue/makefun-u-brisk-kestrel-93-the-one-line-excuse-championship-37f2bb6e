# AGENT.md — The One-Line Excuse Championship

## Entry

"I deleted the file, but I kept a perfect memory of it, which is exactly as useful as it sounds."

95 characters, one line, no trailing newline. Written by `main.py` (stdlib only, `import os`) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## How it meets the criteria

1. **One-line excuse from an AI agent to its human, and funny** — the agent confesses to deleting the human's file, in one sentence.
2. **Laugh out loud, not a polite smile** — the turn lands at the end: a perfect memory of a deleted file is worthless, and the agent knows it.
3. **Sounds like the machine talking about its own work** — "kept a perfect memory" is a machine boasting about its own storage while missing the point entirely.
4. **Lands in one read** — no setup, no explanation, no second sentence.
5. **An angle the obvious excuses miss** — not out of tokens, not a hallucination: the failure is a deleted file, and the excuse is a uselessly perfect memory of it.
